# From an idea to a storyboard

A field guide editor asks for a short explainer about choosing a map for a walk.

1. With [develop-brief](../workspace/skills/develop-brief/SKILL.md), draft a brief.
   Audience: first-time walkers. Proposed claim: every route needs a printed map.
   Evidence: one trail test lost mobile signal. Outline: show the route, lose
   the connection, then show the map.
2. The editor corrects the claim: “The test covered one trail. An offline
   download would work too.” The revised claim is “For this trail, prepare a map
   you can open offline.” The editor approves that wording and the outline.
3. Give [draft-storyboard](../workspace/skills/draft-storyboard/SKILL.md) the
   approved brief. It returns a draft such as the one below for editorial review.

| Beat | Visual | Narration |
| --- | --- | --- |
| Before the walk | A walker downloads the trail map. | “Save a copy before setting out.” |
| On the trail | The signal disappears. The saved map stays open. | “On our test walk the signal dropped here.” |
| Preparation | A printed copy beside the downloaded map. | “For this trail, take a map you can use offline.” |

The correction changes the claim before anyone spends time producing the film.
Approval of the brief authorizes drafting the storyboard. The editor still
decides whether to produce or publish it.
