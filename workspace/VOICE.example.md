# Private voice guide template

Replace this fictional template locally with the owner's approved preferences. Keep the completed guide and private samples outside this public repository.

## Rules across formats

Record language, spelling, punctuation, and vocabulary preferences. Preserve intended meaning, certainty, commitments, and the relationship with the reader. Distinguish assistant replies from drafts in the owner's name.

## References by purpose

| Format | Approved reference | What to learn | Evidence date |
| --- | --- | --- | --- |
| Essay | Private path or approved public URL | Argument, pacing, examples, tone | Date endorsed |
| Project page | Private path or approved public URL | Length, workflow detail, claims | Date endorsed |
| Professional message | Private source reference | Warmth, compression, requested action | Date sent or approved |

Current explicit corrections take precedence. Unaccepted generated drafts do not establish preferences. Engagement metrics alone do not define voice. Before delivery, compare the draft with the closest approved reference.
