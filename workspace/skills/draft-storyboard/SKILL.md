---
name: draft-storyboard
description: Turn an approved explainer brief into a reviewable storyboard draft.
---

Start with a specific approved brief. If it is missing or its claim has changed,
request review of the current version. Draft the narration and visual for each
beat. Check that each factual claim stays within the supplied evidence. Return
the storyboard for review. Rendering paid media, sending and publishing each
require separate authority.
