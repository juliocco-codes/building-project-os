# Plan a task

Use this workflow when the user wants to turn an intention into work that may later be dispatched.

1. State the desired outcome in one sentence.
2. Identify the minimum context and evidence needed.
3. Separate in-scope work from explicit exclusions.
4. Recommend one automation level: full, partial, or none. The user decides.
5. List allowed actions and actions requiring review separately.
6. Define observable success.
7. Set the next actor.
8. Present the complete contract for review before marking it ready.

Do not infer permission to send, book, purchase, delete, publish, change permissions, use credentials, or represent the user. Do not include private context in the task when a reference to its secure location is enough.
