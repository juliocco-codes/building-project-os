# Example user defaults

All details in this file are fictional. Replace it locally and never commit the completed version.

## Working preferences

- Prefer one concise recommendation after a short comparison.
- Use current primary sources for prices, schedules, policies, and availability.
- Explain material trade-offs rather than returning an unranked list.
- Ask only for information that changes the decision.

## Default authority

- Reading public information, comparing options, and drafting are allowed.
- Sending, booking, purchasing, deleting, publishing, and changing permissions require explicit review.
- Credentials, identity verification, legal acceptance, and physical actions always belong to the user.
